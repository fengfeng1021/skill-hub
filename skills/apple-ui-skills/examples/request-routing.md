# Request Routing Examples

## “Use this skill to build an Apple-quality dashboard”

Read:
- SKILL
- build pack
- visual pack
- core pack if interaction is nontrivial
- one platform adapter

If no reference is supplied, synthesize the design brief and implement directly.

## “Use this skill to make my existing React page Apple-quality”

Preserve React. Do not rewrite the project. Use the build + web route, define tokens, implement, run, visually inspect, iterate. Add reconstruction records only if a named Apple behavior materially helps.

## “Use this skill to recreate FaceTime PiP snapping in Rust”

Read reconstruction + generic adapter, query the PiP record, compile/translate canonical physics, then implement and validate the actual interaction.

## “Use this skill to create iOS 26 glass tabs in Flutter”

Read reconstruction + visual + build + mobile adapter, query the relevant Liquid Glass records, implement a performant approximation, and validate the result.

## Principle

The user describes the product goal. The agent owns reference synthesis, context expansion, stack choice, implementation, and QA.
