AI 怎麼幫你裝

提示詞已經寫好了

installPrompt

這筆收錄的完整安裝提示詞。精選組合包會自動展開入口與全部內含資產，不會只裝一個。

installIds

真正要安裝的 registry id 清單；精選組合包已攤平。多選時先合併並去重這個欄位。

promptBlockSingle

單一收錄項目的說明段落。多選攤平 installIds 後，用這個欄位組合提示詞。

includedSkills

精選組合包的內容摘要；一般單一 skill 會是空陣列。

promptTemplate

多選要用的開頭、結尾與分隔字串。開頭裡的 {{count}} 換成實際數量。

forAI

寫給 AI 看的使用說明，這一整頁的規矩在那裡面都有。

要幫忙收錄的話

一句話說明，是唯一的硬規定

卡片上只會顯示一句話。標準只有一個：完全不懂程式的人看一眼就知道這是幹嘛的。

這樣寫

載入中

不要這樣寫

載入中

  • 繁體中文，25 字內，一句完整的話
  • 只講「能幫我做到什麼」，不講「用什麼技術做到」
  • 不要出現 API、函式庫、外掛、框架這類術語
  • 不要寫成「名稱：功能一、功能二、功能三」的羅列
  • 技術細節一律寫進 description，那是點開卡片才看的

資料寫在 registry/skills/<id>.json，格式見 schema。 改完跑 npm run validate 會自動檢查太長、術語與羅列句型。
