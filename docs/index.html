How to

三步驟裝好 skill

  1. 勾選：在卡片右上角勾選想裝的 skill，可以一次選很多個。
  2. 複製：底部會浮出操作列，按「複製安裝指令」拿到一整段提示詞。
  3. 貼上：貼進 Claude Code 或任何能存取檔案的 AI，它會自己下載檔案、放到正確位置、驗證 frontmatter。

給 AI 直接讀的接口

  • llms.txt — 純文字總覽，適合整個貼給 AI
  • api/index.json — 全部資料，含每個 skill 的 installPrompt
  • api/skills/<id>.json — 單一 skill

想收錄新的 skill？

不用自己編輯 JSON。把 repo 開在 Claude Code 裡，直接說「我找到一個不錯的 skill：網址，幫我收進去」， 它會照著 CLAUDE.md 的流程建好資料、重新 build。
